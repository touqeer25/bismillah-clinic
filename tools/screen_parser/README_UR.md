# Windows Screen Parser — v83 (English OCR، مقامی، دستی اسکرول)

یہ **کلینک کے براؤزر سے الگ Windows companion** ہے۔ اس کا مقصد کسی دوسری نظر آنے والی ایپ میں کتاب کا ایک صفحہ منتخب کرکے **آپ کے دستی اسکرول کے دوران خود تصویری فریم محفوظ کرنا، مکمل صفحے کی Preview دکھانا، پھر مقامی OCR + دوہری جانچ + تین مخصوص کتابی profiles سے reviewed staging data بنانا** ہے۔ Snagit یا الگ copy-paste/OCR کی ضرورت نہیں۔ کلینک میں searchable book لگانا الگ آئندہ کام ہے۔ یہ پہلا Windows-targeted قابلِ آزمائش update ہے؛ محفوظ/DRM windows یا نامانوس layouts کے لیے گارنٹی نہیں۔

## Windows پر تنصیب

1. مکمل Bismillah Clinic repository کے root پر یہ update ZIP **extract/replace** کریں؛ صرف update ZIP کا الگ فولڈر چلانا کافی نہیں۔ پرانا ذاتی OCR ڈیٹا خودکار طور پر ضائع/ری سیٹ نہیں ہوگا۔ کلینک کے اصل data JSON نہ بدلیں۔
2. Python 3.11–3.13، الگ Tesseract OCR بمعہ English `eng` اور انٹرنیٹ (صرف پہلی مرتبہ Python پیکج ڈاؤن لوڈ کرنے کے لیے) چاہیے۔ عام `C:\Program Files\Tesseract-OCR\tesseract.exe` خود مل جاتا ہے؛ دوسری جگہ ہو تو `TESSERACT_CMD` دیں۔ OCR کے دوران cloud/API key نہیں چاہیے۔
3. Windows کے repo root سے `INSTALL_SCREEN_PARSER_WINDOWS.bat` اور پھر `START_SCREEN_PARSER_WINDOWS.bat` چلائیں۔ v83 scripts **Store Python کے `python3.12` alias** کو بھی آزماتے ہیں، جب `py` اور `python` دستیاب نہ ہوں۔ اگر BAT نظر نہ آئے تو اسی فولڈر کے PowerShell میں:
   ```powershell
   python3.12 -m pip install --user -r .\tools\screen_parser\requirements.txt
   python3.12 -m tools.screen_parser
   ```
   Python packages کے `Scripts is not on PATH` والے پیلے انتباہ سے پارسر نہیں رکتا۔ اختیاری `.exe` Windows ہی پر `BUILD_SCREEN_PARSER_EXE_WINDOWS.bat` بنائے گا؛ Tesseract پھر بھی نصب ہونا چاہیے۔ **v83 BAT/EXE کو اصل Windows پر ابھی آزمائے جانے کی ضرورت ہے۔**

## پہلی source، چاہے ایڈیشن اور صفحہ نمبر نامعلوم ہوں

- اوپر `＋` → **عنوان اور English profile** لازمی: Synthesis جیسے rubrics = `repertory`، Quick Bed-Side = `prescriber`، Allen MM = `materia_medica`۔ edition، کل PDF/viewer صفحات، پہلے/آخری content pages، author/year **اختیاری**؛ ان کو خالی رکھنے سے کوئی فرضی عدد نہیں بھرتا۔ Book mode میں **`No visible page numbers · capture sequence`** منتخب رکھیں جب دوسری ایپ میں صفحات الگ ہوں مگر نمبرز نہ ہوں۔ اس وقت `Capture #1` **PDF page 1 نہیں** ہے؛ واقعی physical نمبر معلوم ہو تب `… → Edit edition / total / confirmed page range…` سے اس sequence کو تصدیق شدہ نمبر سے مربوط کریں۔ پہلے منظورشدہ صفحے دوبارہ شمار نہیں ہوں گے۔
- اگر اصل .pdf فائل موجود ہے تو `Browse` منتخب کریں: پورے PDF کا کل viewer count لیا جاتا ہے اور physical mode چنتا ہے، مگر **first/last CONTENT** صفحات خود سے درست فرض نہیں کرتا۔ جسمانی PDF `24/750` اور صفحے پر چھپا `1` الگ نمبر ہیں۔ PDF سے مکمل صفحہ براہِ راست پڑھنے کے لیے `… → Read FULL original PDF page…` ہے؛ اس میں screen selection استعمال **نہیں** ہوتا۔ Preview پر source صاف لکھا جائے گا۔
- کوئی counter نہ دکھانے والی ایپ سے نامکمل رینج کی **آزمائش اور جزوی reviewed ZIP** ممکن ہے، لیکن پروگرام پورا ماخذ/کتاب *complete* نہیں کہے گا۔ کل صفحات + پہلے/آخری content pages **آپ خود ماخذ سے تصدیق کرکے** Edit details میں درج کریں اور verification checkbox چنیں؛ تبھی ہر منظور/وجہ سے skip شدہ صفحہ شمار کرکے مکمل ZIP دیا جائے گا۔ محض ذخیرہ شدہ shots سے نامعلوم کل تعداد یا کبھی نہ دکھا ہوا صفحہ اخذ نہیں کیا جا سکتا۔

## اسکرین capture: منتخب کریں → Start → آپ scroll کریں → Preview/Check

1. دوسری ایپ میں **ایک الگ نظر آنے والے صفحے کے بالکل اوپر** جائیں۔ پارسر میں `① Select text area` دبائیں؛ اصل بڑی ونڈو چھپ جائے گی۔ کتاب کے **اسی ایک صفحے کا body/heading** ڈریگ کریں، browser tab/scrollbar/ساتھ والا دوسرا صفحہ نہیں۔ اگر ایک صفحے میں دو *متنی columns* ہیں تو Book setup میں 2 columns دیں؛ دو الگ نظر آنے والے صفحات ایک ROI میں نہ ملائیں۔
2. انتخاب کے بعد **نارنجی حد برقرار رہتی ہے، اس کے باہر چھوٹا floating Start · Stop · Preview · Check page toolbox** آتا ہے۔ حد ROI کے باہر بنتی ہے؛ controls منتخب pixels پر ہوں تو Start انکار کرے گا—toolbox کو باہر لے جائیں۔ `Main / details` سے بڑی ونڈو واپس، `Change area` سے نئی selection۔ اگر موجودہ صفحے پر خام تصاویر ہیں تو area بدلنے سے پہلے انہی تصاویر کو archive کرکے **اسی نامنظور صفحے** کو پھر لینا ہوگا۔
3. `▶ Start` → تصدیق کریں کہ **اسی ایک صفحے کا TOP** فریم میں ہے۔ پہلا RAW فریم فوراً ڈسک پر محفوظ ہوتا ہے، **OCR کا انتظار نہیں**۔ آپ عام طریقے سے نیچے اسکرول کریں؛ پروگرام بدلا ہوا ساکن view خود پکڑتا ہے، اور مسلسل motion پر بھی وقفے سے فریم محفوظ کرکے uncertainty flag کرتا ہے۔ کسی دوسرے صفحے تک جانے سے پہلے اس صفحے کا آخر دکھائیں۔ toolbar پر `saved N raw frames · OCR waiting M` نظر آئے گا۔ صرف موجودہ view کا `📸 Grab` استعمال کریں تو وہ پورا scrolling صفحہ نہیں، فقط ایک shot ہے۔
4. `■ Stop`، پھر `👁 Preview` یا `✔ Check page`: اصل محفوظ تصاویر کی **اوپر سے نیچے stitched image** سامنے آئے گی۔ **نارنجی پٹی** = دو فریموں کا تصویری جوڑ ثابت نہیں ہوا؛ وہ گم متن کی جگہ نہیں بھرتی۔ جوڑ/آغاز/اختتام نامکمل ہو تو source میں واپس جا کر اسی صفحے کا حصّہ دوبارہ لیں یا `… → Recapture current page` سے موجودہ تصاویر archive کریں۔ `Check page` OCR پورا ہونے تک انتظار کرے گا؛ Preview میں اپنے ہاتھ سے **TOP اور BOTTOM** دونوں تصدیق کریں، تب page cross-check ہوگا۔
5. صاف machine check صفحہ خود approve کر سکتا ہے، مگر **100% optical correctness کی گارنٹی نہیں**۔ مسئلہ آئے تو بڑی Review میں محفوظ فریم، پوری stitched Preview، editable OCR، الگ entries/grades اور تمام warnings ہیں۔ `Changed OCR retry` دو مختلف کوششیں، selected-line reread، OCR edit + reparse، structured field correction، یا تصویر سے تصدیق شدہ false alarm/override ہر ایک وجہ کے ساتھ؛ غائب pixels کو false alarm کہہ کر *حقیقتاً* درست نہیں کیا جا سکتا۔ Review مکمل/approved/وجہ سمیت non-content skip کے بعد ہی اگلا الگ صفحہ شروع کریں۔ counter ROI صرف واضح viewer physical `24 of 750` badge کے ساتھ؛ نمبر نہ ہوں تو **ہر صفحے کے آخر پر Check page لازمی**۔

## محفوظ پیشرفت، export اور حدود

- Windows پر drafts/اصل cropped تصاویر/SQLite evidence `%LOCALAPPDATA%\BismillahClinic\ScreenParser\` میں؛ interruption میں OCR سے پہلے محفوظ RAW تصویر restart پر دوبارہ پڑھی جاتی ہے۔ Book/source کی منفرد شناخت، optional edition/verified range، unnumbered capture ordinal، PDF-vs-printed label، page status، تصاویر کے hashes، warnings/corrections، **آج اور current session کے unique نئے approved** اور اگلی pending جگہ محفوظ رہتی ہے۔ reapprove کے وقت ایک صفحہ دوبارہ NEW نہیں بنتا۔ نامعلوم کل pages کے ہوتے ہوئے پوری کتاب کی completeness ثابت نہیں ہوتی؛ درمیان میں کوئی unseen whole page چھوٹا ہو تو بغیر counter سے ٹول خود جان نہیں سکتا۔
- `⬇ Export` مکمل تصدیق شدہ رینج پر ہی **complete staging ZIP**؛ رینج نامکمل ہو تو صاف **PARTIAL / INCOMPLETE** نام اور manifest کے ساتھ صرف approved مواد export کیا جا سکتا ہے۔ بے نام ابتدا کا unlinked Prescriber paragraph الگ `screen_parser/unlinked_continuations.json` میں رہتا ہے؛ اسے غلط نئی symptom/remedy entry نہیں بنایا جاتا۔ Prescriber کا ZIP **دونوں** library content اور explicit-remedy clinical-index data رکھتا ہے؛ clinic search/import ابھی شامل نہیں۔ تصویریں ZIP میں نہیں، صرف hashes۔ ZIP کو clinic data JSON پر unzip/overwrite **نہ کریں** اور حقوق کے بغیر کتاب کا متن عوامی GitHub پر نہ ڈالیں۔
- صرف نظر آنے والی عام Windows ایپ میں capture ممکن ہے؛ محفوظ/DRM windows، بہت تیز اسکرول، انتہائی چھوٹی تحریر اور repeating layouts میں gap/low-confidence warning آ سکتی ہے۔ الگ اصل PDF اختیار زیادہ صاف image دے سکتا ہے مگر ضروری نہیں؛ **اسکرین-اسکرول خودکار capture اصل مقصد** ہے۔ image join، دوسرا OCR اور انسانی چیک مل کر غلطیوں کو کم کرتے ہیں، مطلق ضمانت نہیں۔
- جانچ: `python3.12 -m unittest tests.test_screen_parser_v82 tests.test_screen_parser_v83 -v`؛ سرور پر Linux/Xvfb سے floating selection → real mss multi-frame capture → Preview اور full original-PDF-to-Review GUI آزمائے گئے۔ Windows v82 user مشین پر چل چکا؛ v83 native Windows تکمیل کی تصدیق صارف کے نئے ٹیسٹ سے ہوگی۔
