**فیصلہ کن نتیجہ:**
- 🔒 قفل شدہ ترجمے **≈ ۹۷٪ درست** ہیں — یہ بنیاد مضبوط ہے۔
- ⚙️ خودکار ترجموں میں **تقریباً ۳۵–۴۰٪ غلط یا بے تکے** ہیں۔ مگر غلطیاں زیادہ تر **کم استعمال والے** لیبلوں میں ہیں:
  - جو لیبل ۵ بار یا زیادہ آتے ہیں → زیادہ تر ٹھیک (چند ایک مسئلہ)
  - جو ۱–۴ بار آتے ہیں → **تقریباً آدھے غلط**
- اس لیے **ڈاکٹر کو اسکرین پر** جو نظر آتا ہے اس میں تقریباً **۱۰٪ ظہور (≈۷,۰۰۰)** غلط اردو دکھاتے ہیں۔
- `ctx` (والد+بچہ سیاق، ۱,۹۲۵) میں **≈ ۲۸٪ خراب**۔

## ۲. جانچ کیسے کی گئی

1. ریپو کی مقامی نقل → `tools/coverage_ur.js` · `tools/check_rubric_labels.js` · `tools/qa_ur.js` چلائے (سب ٹھیک چلے: کوریج ۸۵.۳٪، ۰ خرابی، ۹۳۶ تنبیہ، qa مشتبہ ۱۱۱)
2. ہر لیبل کی **کینٹ میں تعداد** نکالی (تاکہ اہمیت کے حساب سے دیکھا جائے)
3. موجودہ `qa_ur.js` سے **سخت** جانچ لکھی (فعل پہلے/اسم بعد، دو حرفِ اضافت ساتھ، ٹوٹے لفظ «ہوے/یے»، صفت اسم کے بعد، ضمیر کا لفظی ترجمہ، قوسین) → **۱,۴۴۹ خودکار لیبل مشتبہ** (qa_ur صرف ۱۱۱ پکڑتا تھا)
4. **ہاتھ سے پڑھ کر** تین نمونے جانچے:
   - نمونہ الف: ۱۲۰ خودکار لیبل، استعمال کے وزن سے → **۲۸ صاف غلط (۲۳٪)** + ۷ بے ربط/غیر یکساں
   - نمونہ ب: ۱۳۰ خودکار لیبل، بلا ترتیب → **≈ ۵۵ غلط (۴۲٪)**
   - نمونہ ج: ۱۴۰ قفل شدہ لیبل → **≈ ۴ غلط (۳٪)**
   - ۷۰ `ctx` → **≈ ۲۰ غلط (۲۸٪)**
5. تمام ۸,۹۹۳ خودکار لیبل موجودہ کمپوزر سے **دوبارہ بنوائے** → ۱,۳۳۵ پر نتیجہ فائل سے مختلف نکلا (یعنی فائل «باسی» ہے یا ہاتھ سے بدلی گئی مگر قفل نہیں)

### ⚠ سب سے بڑا خطرہ: اچھے ترجمے قفل نہیں
کئی **درست، ہاتھ سے سنوارے** ترجمے قفل کے بغیر پڑے ہیں — مثلاً `sitting, while` = بیٹھے ہوئے (۴۳۸ بار)، `standing, while` = کھڑے ہوئے (۱۵۸)، `lumbar region` = کمر کا نچلا حصہ (۶۲)، `heat, during` = بخار کی گرمی کے دوران (۹۰)۔
اگر کمپوزر دوبارہ چلا تو یہ **بگڑ جائیں گے** (بیٹھتے ہوئے · کھڑا ہوتے ہوئے · کمر کے کا حصہ · گرمی کے دوران)۔ **یہی وہ مسئلہ ہے جس کی شکایت پہلے ہو چکی ہے** («ہر بار پچھلی اصلاح بدل جاتی ہے»)۔

## ۶. تجویز کردہ منصوبہ

### مرحلہ ۰ — حفاظت (پہلی نشست) — *کوڈ میں کوئی تبدیلی نہیں*
1. **۸۳۲ خودکار لیبل جو ۵ بار یا زیادہ آتے ہیں** (۲۰,۰۵۴ ظہور = کینٹ کا ۲۸٪) — ایک ایک پڑھ کر درست کروں، غلط سنواروں، اور **سب قفل** کروں۔
   → اس کے بعد کینٹ کا **۷۰٪** (۴۹,۹۰۰ ظہور) نظرثانی شدہ + محفوظ ہوگا۔
2. **یکسانیت:** `agg.` = ہمیشہ «بگاڑ»، `amel.` = «آرام»؛ exertion / talking / coition / vexation / dinner — ہر ایک کا **ایک** اردو طے (آپ کی منظوری سے)۔
3. قفل شدہ میں ملی چند غلطیاں (unaccountable · falling out · …) درست۔
4. فہرست `BATCH_7_REVIEW.md` میں — آپ کی نظرثانی، پھر `merge_ur.js` سے ضم۔

### مرحلہ ۱ — کمپوزر کی اصلاح — *کوڈ بدلنا ہوگا، اجازت درکار*
`tools/compose_ur.js` میں:
- `obl()` مرکب پر صحیح لگے («کھلی ہوا» → «کھلی ہوا»، «رات کا کھانا» → «رات کے کھانے»)
- جوڑتے وقت **قوسین ہٹیں** (یا لغت میں مختصر صورت الگ)
- **اندھے جوڑ** (`A, B` → «A B» اور دو لفظ → «A B») **ختم** → اس کی جگہ «?» (اصول ۶: شک ہو تو خالی)
- عام صفتوں کی مطابقت (cold/warm/hot/deep/slight/strong/left/right/first …)
- جمع کی مجرور صورتیں (چیزیں→چیزوں، رانیں→رانوں، دھواں→دھوئیں …)
- دو حرفِ اضافت کبھی ساتھ نہ آئیں
- **ٹیسٹ فائل** `tests/compose_ur_v107.test.js` — اس جانچ کی ≈۶۰ سنہری مثالیں
- `qa_ur.js` میں سخت قاعدے شامل (فعل پہلے · صفت بعد · ٹوٹا لفظ · دو حرفِ اضافت)

### مرحلہ ۲ — کم استعمال والے خودکار ترجموں کی صفائی
- باقی ۷,۹۵۸ خودکار لیبل (۱–۴ بار) نئے کمپوزر سے **دوبارہ**؛ جو اعتماد سے نہ بنے وہ **فائل سے نکلے** (ایپ پھر ہلکے رنگ کا لفظی ترجمہ دکھائے گی — ایماندار طریقہ)۔ اندازاً ≈۳,۰۰۰ نکلیں گے، ≈۵,۰۰۰ درست ہو کر رہیں گے۔
- `ctx` کے ۱,۹۲۵ میں سے خراب (≈۵۰۰) ہٹیں؛ سانچے (خوف/غصہ/مغالطہ/بیزاری/خواہش) رہیں۔
- نتیجہ: فائل میں **ہر لیبل یا تو نظرثانی شدہ یا قابلِ اعتماد**؛ سخت جانچ پر **۰ مشتبہ**۔

### مرحلہ ۳ — ہاتھ سے ترجمہ، باب در باب (بیچ ۸ سے آگے)
- کل ≈ ۱۳,۰۰۰ لیبل (۱۰,۱۷۲ بغیر ترجمہ + ≈۳,۰۰۰ نکالے ہوئے)
- **ہر بیچ ≈ ۶۰۰ لیبل، ایک باب** → `BATCH_n_REVIEW.md` (انگریزی · اردو · والد ربرک ساتھ) → آپ کی نظرثانی → `merge_ur.js` → قفل
- ترتیب (تجویز): **MIND** (سب سے زیادہ پڑھا جانے والا، کوریج سب سے کم؛ ۳ بیچ) → EXTREMITIES (۲ بیچ) → HEAD (۲) → BACK · GENERALITIES · CHEST · STOMACH · COUGH · MOUTH · EYE · SLEEP · EAR · NOSE (۱–۱) → باقی چھوٹے ابواب جوڑ کر
- اندازاً **۲۰–۲۲ بیچ** = ۲۰–۲۲ نشستیں۔ ہر بیچ کے بعد کوریج بڑھے گی (≈ +۰.۸٪ فی بیچ) → آخر میں **≈ ۹۹٪**
