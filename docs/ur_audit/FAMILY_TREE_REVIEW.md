# کیا ترجمہ اپنی «فیملی ٹری» سے جڑا ہے؟ — جانچ اور نیا منصوبہ
**تاریخ:** ۲۹ ستمبر ۲۰۲۶ · **سوال:** قفل شدہ ترجمے پورے ربرک کے مطلب (جو ڈاکٹر کینٹ کہنا چاہتے ہیں) کے مطابق ہیں یا الگ اپنا مطلب بتا رہے ہیں؟

---

## ۱. سیدھا جواب

**نہیں — موجودہ نظام ربرک کا ترجمہ نہیں کرتا، ٹکڑے کا کرتا ہے۔**

ایپ میں ترجمے کی اکائی «ٹری کی ایک سطح کا لیبل» ہے (`walking` = چلنا، `menses` = حیض)۔ ہر صف پر صرف **اسی صف کے ٹکڑے** کی اردو دکھتی ہے، اور «پورا جملہ» (`repRubricUrFull`) صرف انہی ٹکڑوں کو **الٹی ترتیب میں کوما لگا کر** جوڑ دیتا ہے:

```
ABDOMEN, PAIN, cramping, griping, hypogastrium, eating, after
صفحے کی صف میں:  «کھانے کے بعد»
«پورا جملہ»:      «کھانے کے بعد، پیٹ کا نچلا حصہ، اینٹھن، مروڑ والا، درد»
کینٹ کا مطلب:    «کھانے کے بعد پیڑو (پیٹ کے نچلے حصے) میں مروڑ اور اینٹھن والا درد»
```

قفل شدہ ۲,۳۷۸ ترجمے **لغت کے طور پر ≈۹۷٪ درست** ہیں، مگر:
- ان میں سے **۲,۰۳۴ ذیلی ربرک کے طور پر** استعمال ہوتے ہیں، اور **۱,۰۳۰ تین یا زیادہ مختلف والد ربرکس کے نیچے** آتے ہیں۔ ایک ہی لغوی صورت ہر جگہ کینٹ کا رشتہ نہیں بتا سکتی۔
- **۲,۶۵۷ صفوں** پر ترجمہ صرف ایک ننگا مصدر ہے — «چلنا» «لیٹنا» «بیٹھنا» «کھانا» «کھڑا ہونا» — جبکہ کینٹ کا مطلب ہے «چلتے ہوئے / چلنے سے»، «لیٹنے پر»، «کھانے کے بعد»۔
- کچھ جگہ ٹکڑے کا الگ مطلب **سیاق میں غلط** ہو جاتا ہے (نیچے مثالیں)۔

## ۲. کیسے جانچا

1. ایپ کا اصل کوڈ (`rep-tree.js` + `17-rubric-ur.js`) jsdom میں چلا کر کینٹ کے **تمام ۷۱,۰۲۷ ربرکس** کے لیے وہی نکالا جو صفحہ دکھاتا ہے: (الف) صف کا ترجمہ، (ب) «پورا جملہ»۔
2. ہر باب سے ۳ ربرک بلا ترتیب (کل **۱۱۱**) لے کر تینوں کا موازنہ **کینٹ کے مطلب** سے کیا → `4_family_tree_sample_111.tsv`
3. قفل شدہ لیبلوں کے **والد ربرکس** گنے (کتنے مختلف سیاق میں آتا ہے)۔

### نتیجہ (۱۱۱ ربرکس)
| «پورا جملہ» کیسا نکلا | حصہ |
|---|---:|
| واقعی اردو جملہ، مطلب صاف (زیادہ تر ۲ ٹکڑوں والے: «قبض کے دوران، پھولنا») | ≈ ۲۵٪ |
| ٹکڑوں کی الٹی فہرست — ڈاکٹر خود جوڑ کر سمجھ سکتا ہے، مگر «کینٹ کا کہا» نہیں | ≈ ۴۵٪ |
| **گمراہ کن / غلط** — ٹکڑے کا الگ مطلب سیاق میں غلط، ترتیب/جنس ٹوٹی، یا سانچہ غلط لگا | ≈ ۳۰٪ |

## ۴. اس کا مطلب کیا ہے

- ٹکڑوں کی لغت (قفل شدہ ۲,۳۷۸) **ضائع نہیں** — یہ نئے کام کی اینٹیں ہیں۔ مگر **ربرک کا مطلب** اس سے خود بخود نہیں بنتا۔
- «ہر ربرک کا ترجمہ جو کینٹ کہنا چاہتے ہیں» کے لیے ترجمے کی **اکائی بدلنی ہوگی: لیبل نہیں، پورا ربرک (پورا راستہ)**۔
- کینٹ میں **۷۱,۰۲۷ ربرک** ہیں (۴,۷۰۹ اوپر کی سطح کے)۔ سب ہاتھ سے لکھنا بڑا کام ہے — اس لیے نیچے **دو درجے** تجویز ہیں: (الف) ہاتھ سے لکھا جملہ، (ب) ہاتھ سے لکھے **والد** کے جملے میں **جانچے ہوئے** شرطی ٹکڑے کا اضافہ۔

## ۵. تجویز کردہ نیا ڈھانچہ (کوڈ کی اجازت درکار)

### ۵.۱ نئی فائل — ربرک کی سطح کا ترجمہ، باب بہ باب
```
ur/rubrics/kent/mind.json
{
  "meta": {...},
  "rubrics": {
    "anger, consoled, when":        "تسلی دینے پر غصہ آ جائے",
    "delusions, enlarged, chin is": "وہم کہ ٹھوڑی بڑھ گئی ہے",
    ...
  },
  "locked": [ ... ]        ← نظرثانی شدہ؛ کوئی خودکار عمل نہ چھوئے
}
```
کلید = پورا راستہ (چھوٹے حروف، «(See …)» نکال کر) — وہی جو `coverage_ur.js` استعمال کرتا ہے۔ `kent_chapters/` کی JSON **نہیں بدلتی**۔

### ۵.۲ ایپ میں ترجیح کی ترتیب
```
۱. ربرک کا جملہ (نئی فائل)          ← ہاتھ سے لکھا، نظرثانی شدہ
۲. والد کا جملہ + جانچا ہوا شرطی ٹکڑا   ← صرف اُن ٹکڑوں پر جن کی «جملے والی صورت» منظور ہو
                                        (walking → «چلتے ہوئے»، menses → «حیض کے دوران»، 4 p.m. → «سہ پہر ۴ بجے»)
۳. موجودہ نظام (ctx → لیبل → لفظی)     ← ہلکے رنگ میں، «نظرثانی باقی» کے نشان کے ساتھ
```
ہر صف پر **پورا مطلب** دکھے (والد کا حصہ ہلکا، اِس صف کا اضافہ نمایاں) — یا صرف ہوور/تفصیل پر: **آپ کا فیصلہ**۔

### ۵.۳ لغت میں ایک نیا خانہ: «جملے والی صورت»
موجودہ لغت لفظ کی لغوی صورت رکھتی ہے (`walking` = چلنا)۔ ربرک جوڑنے کے لیے ہر شرطی ٹکڑے کی **جملے والی صورت** چاہیے:
`walking` → چلتے ہوئے · `lying` → لیٹنے پر · `eating` → کھانے کے بعد · `menses` → حیض کے دوران · `motion` → حرکت سے · `old people` → بوڑھوں میں · `suppressed` → (اسم کے مطابق: دبے ہوئے دانوں / دبے ہوئے حیض …)
≈ ۴۰۰ سب سے زیادہ استعمال والے ٹکڑے — ایک نشست میں، آپ کی منظوری سے۔

### ۵.۴ اوزار
- `tools/export_rubrics_ur.js kent mind` → TSV: راستہ · صفحہ اب کیا دکھاتا ہے · والد کا جملہ · خالی خانہ
- `tools/merge_rubrics_ur.js` → قفل کا احترام، شمار «نئے / بدلے / محفوظ»
- `tools/qa_rubrics_ur.js` → ہر باب کا پورا صفحہ اردو میں **پڑھنے کے لیے** نکالے (تاکہ آپ ایک ہی فائل میں پورا باب پڑھ سکیں)
- ٹیسٹ: `tests/rubrics_ur_v107.test.js`

## ۷. فیصلے جو آپ سے چاہئیں
1. ربرک کی سطح والا نیا ڈھانچہ (۵.۱–۵.۴) بنانے کی اجازت؟ (کوڈ بدلے گا؛ ڈیٹا JSON نہیں)
2. صفحے پر ہر صف میں **پورا مطلب** دکھے، یا صرف اِس صف کا اضافہ اور پورا مطلب ہوور/تفصیل پر؟
3. جملے کی ترتیب: **شرط پہلے** («صبح جاگنے پر سر میں درد») یا **بنیاد پہلے** («سر درد — صبح جاگنے پر»)؟
4. پائلٹ MIND سے شروع؟ (یا کوئی اور باب جو آپ روز دیکھتے ہیں)
