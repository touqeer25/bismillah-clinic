## زپ کیسے لگائیں
1. زپ کو ریپو کی **جڑ** میں کھولیں تاکہ فائلیں اپنی جگہ بیٹھ جائیں۔
2. یہ **تبدیلیوں کی زِپ** ہے، مکمل ذخیرہ نہیں؛ اس میں صرف نئی اور بدلی ہوئی فائلیں ریپو کی جڑ کے مطابق رکھی گئی ہیں۔ بیک اپ کے بعد اسے ریپو کی جڑ میں کھولیں تاکہ پرانی فائلیں بدل جائیں؛ گٹ ہب پر بھیجنا صارف کے اختیار میں ہے۔
3. براؤزر میں **دو بار کنٹرول + شفٹ + آر** دبائیں تاکہ پرانی کیش صاف ہو۔
